# OpenGPT Tetris

This repository includes a minimal Tetris implementation using Pygame.

## Installation

Install dependencies with pip:

```bash
pip install -r requirements.txt
```

## Running the Game

Run the Tetris game with:

```bash
python tetris/main.py
```

Use the arrow keys to move and rotate the pieces. Press the down arrow for a soft drop or the space bar for a hard drop. When the game is over, press `R` to restart or `Q` to quit.
